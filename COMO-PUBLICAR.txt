MOSQUITO • CARAVANA CIGANA 2027 — COMO PUBLICAR O SITE + CONTROLE INTERNO
==========================================================================

ESTRUTURA
  index.html      → site público
  admin.html      → painel de controle interno (seusite.vercel.app/admin)
  api/            → funções do servidor (salvar inscrições, login, listar)
  img/  fonts/    → imagens e fonte dos títulos
  package.json, vercel.json → configuração (não apagar)

PASSO 1 — Subir o projeto
  Envie a pasta INTEIRA para o Vercel (pelo GitHub ou pelo comando "vercel"
  dentro da pasta). Não mande só o index.html: a pasta "api" é o sistema.

PASSO 2 — Conectar o banco de dados (uma vez só, grátis)
  No painel do Vercel, abra o projeto →
  aba "Storage" → "Create Database" → escolha "Upstash" (Redis) →
  crie no plano gratuito → "Connect" ao projeto.
  Isso cria sozinho as variáveis KV_REST_API_URL e KV_REST_API_TOKEN.
  Depois vá em "Deployments" → nos três pontinhos do último deploy → "Redeploy".

PASSO 3 — Entrar no painel
  Acesse:  https://SEU-SITE.vercel.app/admin
  Usuário: Mosquito
  Senha:   (enviada na conversa — guarde num lugar seguro)

PASSO 4 — Aviso no WhatsApp a cada novo cadastro (grátis, via CallMeBot)
  O número que recebe os avisos está configurado como (14) 99783-3913 (teste).
  1. No celular desse número, abra https://www.callmebot.com/blog/free-api-whatsapp-messages/
     e salve nos contatos o número do CallMeBot indicado lá.
  2. Mande para esse contato, pelo WhatsApp, a mensagem:
        I allow callmebot to send me messages
  3. Você recebe uma resposta com a sua "apikey" (um número).
  4. No Vercel → Settings → Environment Variables, crie:
        CALLMEBOT_APIKEY = a apikey recebida
        SITE_URL         = https://SEU-SITE.vercel.app   (opcional: link do painel no aviso)
        AVISO_WHATSAPP   = 55 + DDD + número             (opcional: para trocar o número de teste)
  5. Faça Redeploy, entre no /admin e clique em "🔔 Testar aviso".
  Obs.: cada número precisa da sua própria apikey. Se o aviso falhar, o cadastro
  continua salvo normalmente no painel.

TROCAR A SENHA (opcional)
  Vercel → Settings → Environment Variables → crie ADMIN_SENHA com a nova
  senha → Redeploy. A senha antiga deixa de funcionar.

NO PAINEL
  • Setores: Ala Pais e Filhos, Ala das Bandeiras, Destaques, Bateria e
    Abadás avulsos (fora do kit).
  • "+ Novo cadastro" / "+ Cadastrar neste setor": cadastra pessoas que não
    vieram pelo site. "Editar" corrige qualquer cadastro.
  • "Planilha do setor" baixa só a aba aberta; "Planilha geral" baixa um
    Excel com uma aba de Resumo + uma aba para cada setor.
  • Para mudar a lista de posições de destaque ou de instrumentos, edite
    POSICOES e INSTRUMENTOS no início do script do admin.html.

OBSERVAÇÕES
  • A inscrição entra no painel quando a pessoa clica no botão do formulário,
    sempre como "Pendente". A pessoa vê uma confirmação na tela e a equipe
    recebe o aviso no WhatsApp. Se alguém desistir ou duplicar, use "Excluir".
  • Valores dos kits: no final do index.html (constante VALORES_KIT).
  • O arquivo de pré-visualização (mosquito-preview.html) NÃO salva no
    sistema: só o site publicado no Vercel salva.
